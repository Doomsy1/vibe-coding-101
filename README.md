## Tier 1: The Good Stuff

### [Cursor](https://cursor.com/)
You get around $45/month in API credits, and you can snag a free year trial with your [student status](https://cursor.com/students). Great for when you want precise edits done quickly.

### [Claude Code](https://claude.com/product/claude-code)
This is currently the best developer experience, hands down. Claude Opus 4.5 is undoubtedly the best model for coding right now. You get $5-15 of API credits every 5 hours, which is amazing. But be careful, it runs out faster than you'd think. Then you're stuck waiting 4 hours for the next cycle. Worth it though. Also, if your university has a [Claude Builder Club](https://claude.com/programs/campus), you can get free Claude Pro and API credits through that.

### [OpenCode](https://opencode.ai/)
Another CLI tool, and honestly the best user experience of any of them. They provide some free models. Personally, I think Minimax M2.1 is really good. Obviously they'll use your data for whatever they want, but it feels very similar to Claude Code, maybe even more polished. The UI has some finicky behaviors, but overall very solid. You can also plug in other providers like Google to use their API credits, which is nice.

## Tier 2: Solid Alternatives

### [GitHub Copilot](https://github.com/features/copilot)
Not sure exactly how long the trial is, but you get around $80/month of usage. The usage isn't measured in API credits though, so you really want to make the most of every message you send. Students get it free through the [GitHub Student Developer Pack](https://education.github.com/pack).

### [OpenAI Codex](https://openai.com/codex/) (Honorable Mention)
Not free for students in any way, but if you have it, the usage limits are awesome. They're basically throwing money away, and it's a great experience. I wouldn't say it's the best CLI on its own, but you can use it through OpenCode for a better experience.

## Tier 3: Free Options

### [Antigravity](https://antigravity.google/) (Google)
Free for everyone, which is a little concerning because they probably munch on your data. Pretty good usage limits though. Not exactly sure how much, but it works well for planning. The UX isn't great, but it's definitely usable.

### [Gemini CLI](https://github.com/google-gemini/gemini-cli)
Not a good user experience at all. Feels very clunky. But you get credits, around $20 a day, so it's a solid backup.

### [AI Studio](https://aistudio.google.com/)
Not really for coding, but great for chatting. Usage limits? They basically don't exist. Pretty much unlimited.

### [Perplexity](https://www.perplexity.ai/)
With a [student account](https://www.perplexity.ai/students) you get one year of Pro for free. You can use a bunch of different frontier models, which is pretty sweet. Here's my [referral link](https://plex.it/referrals/8N3ELADE) if you want to help me out.

### [Gemini Pro](https://gemini.google/)
Also [one year free for students](https://gemini.google/students/). Not completely unlimited, but it's hard to actually hit those usage limits.

## Pro Tips

### Use LSP
LSP stands for Language Server Protocol. Basically, it lets the AI see real-time errors from your editor, like type errors, missing imports, and syntax issues. So instead of spitting out broken code that you have to fix yourself (or wait for it to rerun), it catches mistakes as it writes. Seriously, turn this on.

### Use Subagents & Skills
These are basically really good prompts that the model can decide to use. They make a huge difference.

**Subagent Resources:**
- [Claude Code Subagents Docs](https://code.claude.com/docs/en/sub-agents)
- [Awesome Claude Code Subagents](https://github.com/VoltAgent/awesome-claude-code-subagents)

**Skills Resources:**
- [Claude Code Skills Docs](https://code.claude.com/docs/en/skills)
- [Official Anthropic Skills](https://github.com/anthropics/skills)
- [Awesome Claude Skills](https://github.com/ComposioHQ/awesome-claude-skills)

### OpenCode Parallel Sessions
Cool trick: you can start multiple sessions and have them running in parallel, all from one terminal window. No need to open multiple terminals.

### Use Voice Dictation
[Wispr Flow](https://wisprflow.ai) is a voice dictation tool that actually understands code. You can speak naturally and it formats everything correctly, including syntax, file names, and code structure. It has deep integrations with Cursor, and VS Code. ## My Workflow

Here's how I actually use these tools:

| Situation | Tool |
|-----------|------|
| Starting from scratch, need to plan | **Claude Code** (Plan Mode) |
| Quick, precise edits | **Cursor** |
| Random vibe coding experiments | **OpenCode** |
| Don't want to burn credits on something | See below |

### Credit Management Strategy
When I don't want to use my good credits on something less important:
1. Use **Claude Code** until credits run out
2. Switch to **OpenCode** or **Cursor**
3. Fall back to **Copilot**, **Antigravity**, or **Gemini CLI**

It's rare that I run out of all of them, but it does happen sometimes.
